UX / Front-End Case Study

Elektrárna Dukovany II — Homepage

From Figma design system to a responsive, static one-page site

Project Overview

  • Static, responsive one-page website for the Dukovany II nuclear power plant project
  • Built directly from a Figma design file using design tokens (color, spacing, radius, typography)
  • Plain HTML, CSS, JavaScript — no frameworks, no build step
  • Czech-language content, English translation added later

Project Summary

  • Header with logo, main navigation, and CZ/EN language switcher
  • Full-width parallax hero section with description and CTA
  • Blog / news section with four alternating article cards
  • Simple footer
  • Fully responsive across desktop, tablet, and mobile breakpoints

Your Role and Duration

  • Role: Front-end implementation from existing Figma design
  • Scope: design-token extraction, markup, styling, interactions, QA fixes
  • Duration: single iterative working session, delivered in incremental commits
  • Tools: Figma MCP (design context, asset export), HTML/CSS/JS, Python/PIL for favicon

The Problem

  • Design existed only as a Figma component library (atoms, molecules, organisms) — not a single ready-to-export page
  • No frontend framework allowed, so all layout logic had to be handled with plain CSS
  • Needed to preserve exact brand colors, spacing, and radii while making the page fully responsive
  • Interactions (menu states, language bubble, anchor scrolling, parallax) had no direct Figma equivalent — behavior had to be interpreted, not just copied

Goals

  • Pixel-faithful translation of Figma tokens into CSS custom properties
  • Clean, accessible, semantic HTML structure
  • Smooth, precise interactions: active/hover nav states, language switcher, anchor scroll, parallax hero
  • Consistent responsive behavior — no visual misalignment across breakpoints
  • Lightweight, dependency-free, easy to hand off and iterate on

Design Process

1. Design audit & token extraction

  • Explored the Figma file structure: Atoms → Molecules → Organisms → Logical Units
  • Located the actual page composition inside "Logical Units" (Header + Body, Desktop variants)
  • Extracted design tokens via Figma MCP: colors, radii, spacing scale, font family (Inter Tight)
  • Exported the flattened logo mark as a single asset instead of rebuilding 26+ separate vector layers

2. Structure & markup

  • Header: logo, desktop nav bar, mobile hamburger, language switcher
  • Hero: full-bleed image, description copy, primary CTA
  • Blog: four alternating image/text article cards
  • Footer: simple copyright line
  • Semantic tags (header, main, section, article, footer) for accessibility and structure

3. Styling system

  • CSS custom properties for every color, radius, and spacing value from Figma
  • Mobile-first-adjacent breakpoints at 900px / 860px / 640px
  • Reused the same horizontal padding value across header and content at every breakpoint to keep a consistent vertical alignment line with the logo

4. Interaction design (iterative, based on feedback)

  • Active vs. hover states for main nav items
  • Language switcher: hover state + click-to-open bubble (CZ/EN), selected state with checkmark icon
  • Fixed a contrast bug where selected + hovered language option became unreadable (blue on blue)
  • CTA button anchor-scrolls to the blog heading, offset precisely for the sticky header height
  • Blog cards: hover elevation + image scale, no click-through behavior by design
  • Parallax effect on the hero image using a scroll-based transform, respecting reduced-motion preference

5. Mobile navigation refinement

  • Converted mobile menu to a full-screen overlay using position: absolute so it never pushes page content
  • Locked body scroll while the mobile menu is open
  • Closed the menu automatically on link click
  • Iterated on padding, spacing, and centering until menu items sat as clean, centered pill buttons
  • Increased the language bubble's touch target size for easier mobile tapping
  • Raised the language switcher's z-index above the mobile menu overlay so it stays usable while the menu is open
  • Moved the hamburger icon closer to the language switcher for a tighter, more intentional header grouping

6. Content & localization

  • Wrote Czech copy for all four blog articles based on the plant's real context
  • Added a full English translation layer via data-en attributes, swapped on language switch — including image alt text and aria-labels

7. Polish & QA

  • Generated a custom favicon (multiple sizes + ICO) matching the brand's swirl mark and color palette
  • Re-checked spacing alignment across breakpoints after each change — caught and fixed a mismatch between the header and content padding in the tablet range
  • Packaged the final deliverable as a downloadable zip for easy handoff
